# 🌐 AI Website Summarizer 🤖

An AI-powered **Website Summarizer** that takes a website URL as input and uses an **LLM** to generate a concise and easy-to-understand summary.

## ✨ Features

- 🔗 Enter any website URL
- 🌐 Extract website content
- 🤖 Generate summaries using an LLM
- 🎨 Simple and interactive UI with Gradio
- ⚡ Quick and easy to use

## 🔄 How It Works

```text
Website URL 🔗
      ↓
Fetch Website Content 🌐
      ↓
Process Content 📄
      ↓
LLM 🤖
      ↓
Generate Summary ✨
```

## 🛠️ Tech Stack

- 🐍 Python
- 🤖 Large Language Model (LLM)
- 🎨 Gradio
- 🌐 Web Content Processing
